# build-llm-from-scratch

This repository contains the code for developing, pretraining, and finetuning a GPT-like LLM and is heavily inspired from Vizuara YouTube Channel's playlist Building LLMs from Scratch which is in turn inspired on the book Build a Large Language Model (From Scratch) written by Sebastian Raschka.

As I embark on this journey of learning to Build LLMs from Scrath, I will write my understandings into a journal and upload on my github.io page. 

Journal Link: https://mcrao.github.io/journal/build-llm-from-scratch/
